# create-hana

TypeScript CLI that scaffolds Node.js, React, and Vue projects.

## Commands

- `pnpm install`
- `pnpm dev`
- `pnpm build`
- `pnpm typecheck`
- `pnpm lint`
- `pnpm test`
- `pnpm test:smoke`
